# 展演模式全體自動播放

先勾選「展演模式」，再勾選「全體自動播放」。所有篩選後展示的作品（包括畫面下方的作品）會各自進行互動。取消勾選或離開展演模式會釋放長按並停止自動操作；作品原本的動畫可以繼續。切換到其他分頁時暫停自動操作，回到藝廊後恢復。

`gallery_autoplay.js` 使用單一排程，交錯執行每件作品的滑鼠／指標點擊、移動與拖曳。篩選或排序重建 iframe 時會清理舊狀態，再接上新作品。隱藏作品不載入 HTML，避免零尺寸畫布及不必要的動畫耗用。

特殊流程：

| 作品 | 展演操作 |
| --- | --- |
| 徐妏寧 | 準備好了 → 原作品燃燒動畫 → 防火按鈕；作品自行重置後再次進入 |
| 蔡佳翰、陳子怡、陳翰博 | 操作各自的音訊／進入控制，再進行畫面互動 |
| 連浡崴 | 通過入口，輪流展示 PURE、REVERIE、DEEP |
| 林妤庭 | 暫存示範日記 → 選擇類別 → 儲存示範彈珠 → 拉桿／發射；不寫入 localStorage，結束後還原原日記與輸入 |
| 翁圓舒 | 建立一個視覺記憶與泡泡，避免觸發 prompt 對話框 |
| 楊靜慧、黃政文 | 自動滾輪搭配點擊 |
| 陳陽安 | 水面區域長按超過 5 秒 |
| 黃鈺倢 | 長按前進 → 自動挑色／確定 |
| 楊漢軒 | 交替短按、拖曳及原地長按 |
| 王欣怡 | 交替戳泡泡與點擊玻璃 |
| 鍾佩蓉 | 指標按壓／拖曳；合成事件略過原生 pointer capture |

音訊仍依瀏覽器的播放權限與原作品音訊來源處理。自動操作不代表能繞過麥克風、相機或音訊播放權限。狀態數字表示已接上自動操作的作品數。

2026-10-02 使用 Chrome / Playwright 驗證 33 件作品、特殊入口與防火 UI、點擊／拖曳／滾輪、停止、排序、篩選、390px 手機版，以及既有 localStorage 日記和未送出文字的還原。完整測試無新增 JavaScript 執行錯誤。新增控制器沒有加入外部套件、網路請求或任意程式執行；UI 操作使用明確的作品白名單。
